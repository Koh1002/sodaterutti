# たまごっちゲーム 画像生成プロンプト集（Nano Banana Pro対応版）

> 著作権キャラクター参照・制限ワードを除去した修正版
> 全67枚分のプロンプトを記載

---

## 使い方

1. 各プロンプトをそのままコピーしてNano Banana Proに投げる
2. 生成後、ファイル名を `suggested_filename` の通りにリネームして `public/images/` 以下に配置
3. スプライトシート（表情差分）は手動で分割するか、CSSスプライトとして使用

## カテゴリ2: キャラクター表情差分スプライトシート（22枚）

各キャラクター（#01〜#22）に対して以下のテンプレートで生成。`[CHARACTER_DESC]` を各キャラの外見特徴に差し替え。

### テンプレート
```
A 2x2 grid sprite sheet of a cute [CHARACTER_DESC]:
Top-left: eating happily with open mouth holding food,
Top-right: playing excitedly and jumping with sparkle effects,
Bottom-left: sleeping peacefully with closed eyes and "zzz" text,
Bottom-right: feeling unwell with pale color and sweat drop and dizzy spiral eyes.
Same consistent character design across all four panels,
smooth clean vector illustration style, white background,
transparent PNG, kawaii cute game aesthetic.
Size: 512x512px (each panel 256x256px)
```
